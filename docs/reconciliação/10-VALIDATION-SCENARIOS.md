# Catálogo inicial de cenários para explorar

Estes itens são candidatos, não requisitos confirmados.

- perda de internet durante partida;
- reconexão após período offline;
- envio duplicado de evento;
- dois dispositivos alterando a mesma partida;
- correção de placar;
- alteração após homologação;
- usuário sem permissão tentando editar;
- troca de papel/permissão durante operação;
- relógio de dispositivos divergente;
- navegador encerrado durante registro;
- atualização da aplicação durante evento;
- serviço de backend temporariamente indisponível;
- alta concentração de espectadores;
- inconsistência entre placar oficial e placar exibido;
- mudança futura de regra esportiva.
